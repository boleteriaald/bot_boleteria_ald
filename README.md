# Monitor de Disponibilidad de Boletas - Tuboleta

Herramienta automatizada para monitorear la disponibilidad de boletas en Tuboleta y agregar automáticamente al carrito cuando están disponibles, con notificación por WhatsApp.

**Evento:** MIGUEL BOSÉ - IMPORTANTE TOUR 2026  
**Fecha:** 11 de marzo de 2026, 21:00  
**Lugar:** Movistar Arena, Bogotá

## ✨ Características

- ✅ Monitoreo automático de disponibilidad cada 5 segundos
- ✅ Selección automática de asientos cuando hay disponibilidad
- ✅ Agregación automática al carrito
- ✅ Notificación instantánea por WhatsApp
- ✅ Interfaz clara con logs detallados
- ✅ Fácil de configurar y usar

## 📋 Requisitos previos

- Python 3.10 o superior
- Google Chrome instalado
- Conexión a Internet
- Cuenta de WhatsApp (para recibir notificaciones)

## 🚀 Instalación rápida

### Paso 1: Instalar Python

Descarga Python 3.10+ desde https://www.python.org/

Durante la instalación, **marca la opción "Add Python to PATH"**

### Paso 2: Descargar este proyecto

Descarga y descomprime el archivo `tuboleta_monitor.zip`

### Paso 3: Instalar dependencias

Abre una terminal en la carpeta del proyecto y ejecuta:

```bash
pip install -r requirements.txt
